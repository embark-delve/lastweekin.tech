Critical Everest Forms Pro flaw exploited to take over WordPress sites

BleepingComputer General Tech

Hackers are actively exploiting CVE‑2026‑3300, a critical vulnerability in Everest Forms Pro (v 1.9.12 and earlier) that lets an unauthenticated attacker inject arbitrary PHP code via the plugin’s Complex Calculation feature. The flaw arises because user‑supplied values are inserted into a PHP string and executed with `eval()`, and the sanitization used (`sanitize_text_field()`) fails to escape single quotes, enabling attackers to close the string and inject code such as `wp_insert_user()` to create rogue administrator accounts. Wordfence reports show active exploitation began on April 13, with over 29,300 blocked attempts and two main source IPs (202.56.2.126 and 209.146.60.26). The issue was reported in February, patched on March 18, but administrators should still audit logs and accounts—especially for the username “diksimarina”—and block the identified IPs to mitigate the risk.

WIRED General Tech

Lenovo’s IdeaPad Slim 5x proves that a budget laptop can feel premium without compromising too much on usability.
